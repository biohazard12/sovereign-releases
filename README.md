# Sovereign — Update Channel

This repository is the public update channel for the **Sovereign** app
("Your phone, your rules." — Sovereign Labs). It holds release metadata only:

- `update-beta.json` — latest closed-beta version
- `update-public.json` — latest public version

**There are no APK downloads in this repository.** Beta builds are delivered
only to rostered testers through the Sovereign beta gate, and the public
release opens at launch. The Sovereign app checks the JSON file for its
channel to learn whether an update exists.

Source code for Sovereign is not published here — releases ship as APKs only.
